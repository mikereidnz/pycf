# pycf Audit Report (v0.1.0.dev0+c2b0e43)

Companion to `plan/audit_2026-04-28_111858_plan.md`. Scan run on
2026-04-28 (local). Mode: unattended audit per the protocol from
`plan/audit_2026-04-27_171732_plan.md` §5; build/test artefacts may be
modified, **no source files modified** during the scan.

## 1. Executive Summary

Overall health: **good and improving**. Builds cleanly with **zero
compiler warnings** (down from 6 last audit), all C and Python tests
pass (24 C tests + **431 pytest tests, 16 skipped**), coverage is
**90.6%** overall (up from 67% in the first audit), and most of the
release-blocking pre-commit / static-analysis findings from the
previous two audits are resolved.

Highest-risk active issues are now lower-impact:

1. **N-1: pre-commit `exclude` regex did not survive the test
   directory restructure.** Trailing-whitespace and end-of-file hooks
   silently rewrite integration test fixture files under
   `tests/integration/<dir>/matel/` because the exclude regex still
   matches only `tests/<dir>/matel/`. Confirmed: a `pre-commit run
   --all-files` rewrites 17 matel files. The current pytest suite
   tolerates it (whitespace-only changes), but the fixtures are
   explicitly meant to be byte-faithful to the producing tools and
   the comment in `.pre-commit-config.yaml` says exactly that.

2. **N-2: black-via-pre-commit reformats the recently-added
   `ImportTensors` code in `pycf/import_sljm.py`.** Commits
   `cd30b51` and `c2b0e43` were not run through black. The CI
   pre-commit gate (per the plan) will fail on this branch the
   moment it runs against `pycf/import_sljm.py`.

3. **N-3: Sphinx autodoc references in `docs/legacy/reference.rst`
   use bare module name `cfl.X`** (`cfl.Hamiltonian`, `cfl.Tensor`,
   etc.) rather than `pycf.cfl.X`. `sphinx-build` reports 238
   warnings, of which **20 are missing-attribute errors**, and the
   API reference page is effectively empty in the rendered HTML.

Release-readiness: **yes** for internal/scientific use. Numerical
behaviour is unchanged; the spin-half eigenvector regression test
added in `tests/unit/test_import_tensors.py` continues to guard the
`solve_hermitian_block` conjugation fix.

## 6. Test and Documentation Gaps

- Sphinx API reference is effectively empty (N-3); user-visible docs
  do not list the new `ImportTensors` class.
- CHANGELOG.md does not yet record the legacy-vs-new behavioural
  deltas described in the previous plan §4.6 (carried forward) — see
  N-5.
- `pycf/__init__.py` shows 48% coverage (16/31 lines unexecuted),
  primarily the lazy `__getattr__` branches for the optional
  re-exports. A short import-side-effect test (`assert
  pycf.ImportTensors is import_sljm.ImportTensors`) would close
  several of these without functional risk.
- `set_error_handler` end-to-end test from §4 of the previous
  report is still missing; not regression-blocking but worth tracking.

## 7. Suggested Remediation Order

Rationale: highest-risk first, then cosmetic.

1. **N-1** (pre-commit exclude regex) — one-line fix in
   `.pre-commit-config.yaml`. Either `(tests|examples)(/[^/]+)+/matel/`
   or `(tests|examples)/.+/matel/`. Verify by re-running
   `pre-commit run --all-files trailing-whitespace`.
2. **N-2** (black-reformat ImportTensors code) — run
   `black --line-length=100 pycf/import_sljm.py` and commit the
   resulting whitespace-only diff. Check no other files diverge.
3. **N-3** (Sphinx autodoc namespace) — replace `cfl.X` → `pycf.cfl.X`
   in `docs/legacy/reference.rst` (20 occurrences). Re-run
   `sphinx-build` and confirm warnings drop sharply. Consider adding
   `-W` to the docs CI gate to keep this from regressing.
4. **N-4** (unused `Union` import) — drop the `Union` token from the
   `typing` import line in `pycf/import_sljm.py`. Trivial.
5. **N-5** (CHANGELOG entries) — backfill the v0.1.0 changelog with
   the legacy-vs-new deltas and the new `ImportTensors` class (could
   piggy-back on the next release-prep pass).
6. **N-7** (flake8 hook version drift) — bump pre-commit's flake8
   from 6.1.0 to 7.x (matching the dev environment). Optional;
   alternative is to live with two false-positive E402s.
7. **N-8** (`cfl/test` stray file) — either gitignore `cfl/test` or
   change the `test` target to `touch .test-stamp`. Cosmetic.
8. **N-6** (35 mypy errors) — incremental typing cleanup; not
   release-blocking.
9. **N-9** (stale memory) — re-store the Python-floor memory.

### 8.2 Sphinx warnings sample (N-3)

```
WARNING: autodoc: failed to import 'StateLabels' from module 'cfl';
AttributeError: module 'cfl' has no attribute 'StateLabels'
WARNING: autodoc: failed to import 'Tensor' from module 'cfl'; …
WARNING: autodoc: failed to import 'Hamiltonian' from module 'cfl'; …
…
```

The `sys.path.insert(0, os.path.abspath(".."))` in `docs/conf.py`
puts the repo root on `sys.path`, so `import cfl` resolves to the
top-level `cfl/` directory (the C library source tree), not
`pycf.cfl`. The directives need `pycf.cfl.X`.
