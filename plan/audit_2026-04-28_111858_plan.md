# Plan for Auditing the pycf Repo (follow-up audit)

This audit follows the protocol established in
`plan/audit_2026-04-27_130831_plan.md` and refined in
`plan/audit_2026-04-27_171732_plan.md`. The structure, severity model,
and unattended-execution rules from those plans apply here unmodified.

The intent of this third audit is:

- Re-validate that the build and test surface is still healthy after the
  recent merges (PR #6 CI work, dependency floor bump to scipy >=1.15
  and Python >=3.10, test directory reorganisation, ImportTensors
  refactor, and the `cfl_util`/`spinh`/`SpinH`/`njsymbols` test-coverage
  push).
- Re-run the static-analysis tooling and confirm that the F-005,
  F-006, F-007 cleanup performed in the previous audit is still in
  effect (i.e. that bandit / semgrep / pre-commit configs are sane,
  hooks are not silently rewriting files, etc.).
- Re-check the Manual Review Targets in §5.5 of the previous plan,
  with explicit attention to:
  - `ImportTensors` — newly added, not previously audited.
  - `ImportSLJM` — refactored to delegate to `ImportTensors`, so
    re-confirm behaviour preservation is end-to-end clean.
  - `cfl/src/cfl_h.c::solve_hermitian_block` — the conjugation fix at
    line 160 is now guarded by the parametrised eigenvector tests in
    `tests/unit/test_import_tensors.py`; verify it still works under
    sanitizers.
- Track movement on findings still open from the previous audit
  (F-002 mypy, F-008 cfl_error.h header-static, F-009/F-010 Cython
  hygiene, F-011 pyemp.py dead refs, F-013 `make asan` target,
  F-015 docs `_build/` tracking).
- Surface any new findings introduced since `c2b0e43`.

## Scope deltas vs the previous audit

- `ImportTensors` (new class in `pycf/import_sljm.py`) and its 33
  unit tests under `tests/unit/test_import_tensors.py` are first-time
  audit material.
- `ImportSLJM.__init__` was shortened by ~30 lines to delegate to
  `ImportTensors`. Re-check its public surface and behaviour
  preservation.
- The test directory was reorganised into `tests/unit/` and
  `tests/integration/{ceylf,eryso,inten,spin-half}/`. Re-validate
  that pytest discovery still picks up everything and that
  `--cov=pycf` reflects the new layout.
- Python 3.8/3.9 were dropped; `scipy>=1.15`. CHANGELOG and
  `pyproject.toml` should be consistent. Memory store still claims
  `>=3.8` for one note — verify.
- The `[docs]` extra and `make -C cfl asan` target work suggested in
  the previous audit may or may not have landed; re-check.
