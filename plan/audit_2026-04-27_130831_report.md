## Findings

| ID | Severity | Confidence | Component | Evidence / impact | Recommended remediation |
|---|---|---|---|---|---|
| F1 | **High** | confirmed | Packaging | `pyproject.toml:37` places `include-package-data = true` under `[project]`, causing `python setup.py build_ext --inplace` to fail before extension build. This blocks clean local rebuilds and release builds using current setuptools validation. | Move `include-package-data = true` under `[tool.setuptools]` or remove if redundant, then rerun build/install paths. |
| F2 | **High** | confirmed | C native layer | `cfl/src/cfl_h.c:645-648` assigns `hd_w->coeff_w = zhcsrsama_alloc(...)` then immediately dereferences `hd_w->coeff_w->hcsr_m`. `zhcsrsama_alloc` has multiple `CFL_ERROR_NULL` allocation-failure paths in `cfl/src/cfl_csr.c:616-640`. | Add a NULL check and cleanup path after `zhcsrsama_alloc`; make `zhcsrsama_free(NULL)` safe (`cfl/src/cfl_csr.c:759-768`). |
| F3 | **High** | likely | Cython/native boundary | `pycf/cfl.pyx:207-220` passes CSR arrays directly into `zt_csr_alloc` using `&row_ptr[0]`, `&col_in[0]`, `&val[0]` without checking non-empty `row_ptr`, CSR monotonicity, `row_ptr[-1]` vs `len(col_in)/len(val)`, or column bounds. Invalid user input could lead to native out-of-bounds reads/writes or wrong tensors. | Validate CSR invariants in Cython before entering C. Add tests for empty/inconsistent CSR arrays. |
| F4 | **Medium** | confirmed | Cython API | `Hamiltonian.__cinit__` uses `tensors[0].n` at `pycf/cfl.pyx:402-405` without explicit empty-list validation. Dimension validation is also implicit; C checks state-label hashes in `cfl/src/cfl_h.c:90-101`, not a clear Python-facing contract. | Raise clear `ValueError` for empty tensor lists and incompatible dimensions/state labels before native allocation. |
| F5 | **High** | confirmed | Optional dependency / API | `pycf/pyemp.py:56-58` imports matplotlib at module import time and `pycf/pyemp.py:1173` registers a projection globally. `matplotlib` is only in optional examples deps (`pyproject.toml:46-49`, `setup.py:301-304`). Minimal installs cannot import `pycf.pyemp` without optional deps. | Lazy-import matplotlib in plotting-only paths, or move matplotlib to base dependencies if `pyemp` is intended as always importable. |
| F6 | **High** | confirmed mismatch, scientific impact likely | `paramcalc.Xi_val` | Docstring says Yb values are linearly interpolated from Er and Tm (`pycf/paramcalc.py:46-47`), but implementation returns a hardcoded Yb table entry (`pycf/paramcalc.py:65-88`). Either the documentation or values are wrong; this is a scientific-correctness risk. | Confirm intended Krupke/Yb source. Either implement interpolation explicitly or correct the docstring and add regression tests for Yb values. |
| F7 | **Medium** | confirmed | Dependency metadata | `pyproject.toml` and `setup.py` disagree on optional dependency constraints, e.g. matplotlib `>=3.8` vs `>=3.5`, pytest-cov `>=7.0` vs `>=4.0`, pytest-benchmark `>=5.0` vs `>=4.0`. | Make `pyproject.toml` the source of truth or synchronize `setup.py` constraints. |
| F8 | **Medium** | confirmed | Type checking | `mypy` fails with many errors. The first failures are in `pycf/pyemp.py` around optional/None handling and dynamically-created attributes; more appear in `cfl_util.py`, `inten.py`, and `import_sljm.py`. | Decide whether mypy is advisory or required. If required, start with pyemp annotations/dynamic attributes or exclude intentionally dynamic code with targeted config. |
| F9 | **Medium** | confirmed | Test coverage | Main pytest passes, but total coverage is `65%`; `pycf/pyemp.py` is 0% and omitted by `pytest.ini:6-8`. `spinh.py` is 72%, `cfl_util.py` 79%, `import_sljm.py` 84%. | Add targeted tests around public parsing/error paths and pyemp import behavior; keep pyemp coverage exclusion only if explicitly documented as external-tool-only. |
| F10 | **Low** | confirmed | C warnings | `make -C cfl` emits repeated warnings about `_cfl_default_error_handler` / `_cfl_error_handler` being static but used in inline functions in `cfl_zefoz.c` and `cfl_sh.c`. | Triage warning root cause; fix if it affects portability or stricter compiler settings. |
| F11 | **Medium** | confirmed | Importer docs/error handling | `ImportSLJM.__init__` opens `name.mi_` and `sl_name.st_` directly (`pycf/import_sljm.py:75-96`), so missing files surface as raw `FileNotFoundError`. The label convention FIXME at `pycf/import_sljm.py:117-119` remains unresolved. | Add contextual file-loading errors and document/resolve the `T` vs `X` label convention with tests. |
| F12 | **Medium** | confirmed | Intensity units / maintainability | `pycf/constants.py` documents SI constants, while `pycf/inten.py:145-150` hardcodes CGS-style constants locally. This may be intentional, but the unit boundary is not centrally documented. | Either centralize CGS variants/conversions in `constants.py` or document why `inten.py` uses local CGS constants. |

## Test and documentation gaps

- Slow tests need either runtime expectations, progress logging, or targeted splitting; the current `--runslow` run did not complete in a reasonable unattended window.
- Benchmark tests run during the default pytest suite when `pytest-benchmark` is installed, which makes normal test output noisy and can obscure audit output.
- The packaging docs say `python setup.py build_ext --inplace` is the rebuild command, but that command currently fails because of `pyproject.toml`.
- Legacy/scientific deltas are partially documented in the plan, but Yb `Xi_val`, intensity unit systems, and importer label conventions need stronger source-backed baselines.

## Suggested remediation order

1. Fix `pyproject.toml` metadata so clean extension builds and editable installs are reliable.
2. Add native/Cython validation and NULL handling around tensor/Hamiltonian construction and `zhcsrsama_alloc`.
3. Resolve the `Xi_val` Yb documentation-vs-implementation mismatch with a regression test.
4. Decide pyemp's dependency contract: lazy matplotlib import or base dependency.
5. Split or time-bound slow tests and keep benchmarks out of default pytest unless intentionally desired.
6. Align dependency metadata, then address mypy/pre-commit/static-analysis noise incrementally.
