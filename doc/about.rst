About pycf
==========

pycf is a collection of python modules for crystal field theory and spin
Hamiltonian calculations.  The primary module for crystal field theory is pyemp,
which wraps Michael F. Reid's F-shell emprical crystal field theory routines.
Spin Hamiltonian calculations are done with the spinh module.

Documentation conventions
-------------------------

Names of classes, objects, constants, etc. are given in **boldface** font.
Often there are also links to a more detailed documentation of the
referred object.

This manual contains many examples of use, usually prefixed with the
Python prompt ``>>>`` (which is not a part of the example code).
